# FrameBurst 1.1.0

FrameBurst can now save HDR screenshots. It's off by default, so nothing changes unless you turn it on.

## Download

**[FrameBurst-Setup-1.1.0.exe](https://github.com/LunoviaVR/FrameBurst/releases/download/v1.1.0/FrameBurst-Setup-1.1.0.exe)**:
run it and follow the steps. If you already have FrameBurst installed, it will offer this update on its own
(or choose **Check for updates** from the tray menu). Your settings are kept.

**Requirements:** Windows 10 version 2004 or later, or Windows 11 (64-bit), and a Direct3D 11 GPU.

## What's new

### HDR screenshots (optional)
- New setting: **Settings › Output › Save HDR copy**. It's **off by default**.
- When it's on and you capture an area that includes a monitor with Windows HDR turned on, FrameBurst also
  saves a second file next to the normal one, named `…_HDR.png`.
- The HDR file is a 16-bit PNG in BT.2100 PQ (BT.2020 colours), tagged so HDR-aware viewers such as
  Chrome, Edge and recent image editors show the full brightness range. The conversion runs on the GPU like
  the rest of the capture.
- The normal PNG, the clipboard and the editor work exactly as before, so you can still paste and share
  screenshots anywhere.
- The HDR copy is the unedited capture: annotations and the mouse cursor only go into the normal PNG.
- Nothing extra is saved for SDR monitors, or when *Save to file* is off.
