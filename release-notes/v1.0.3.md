# FrameBurst 1.0.3

The update messages now match the new FrameBurst look, rather than showing the old grey Windows message boxes.

## Download

**[FrameBurst-Setup-1.0.3.exe](https://github.com/LunoviaVR/FrameBurst/releases/download/v1.0.3/FrameBurst-Setup-1.0.3.exe)**:
run it and follow the steps. If you already have FrameBurst installed, it will offer this update on its own
(or choose **Check for updates** from the tray menu). Your settings are kept.

**Requirements:** Windows 10 version 2004 or later, or Windows 11 (64-bit), and a Direct3D 11 GPU.

## What's new

### Redesigned update dialogs
- **Check for updates** now answers in a window styled like Settings, with the Mica background, the
  FrameBurst title bar, a clear heading and Fluent buttons. It follows your light or dark theme.
- This covers every update message: "You're up to date", "Couldn't check for updates", the
  update-available prompt (with release notes) and "The update failed".
- The update prompt now has clear buttons, **Install now** and **Not now**, in place of Yes / No.
- Error details in these dialogs can be selected and copied.
- **Enter** picks the highlighted button and **Esc** closes the dialog.
