# FrameBurst 1.0.1

A look refresh: the Settings window and the tray menu are now built with **WinUI 3**, so FrameBurst looks and
feels like the rest of Windows 11. Capture, hotkeys and output work exactly as before.

## Download

**[FrameBurst-Setup-1.0.1.exe](https://github.com/LunoviaVR/FrameBurst/releases/download/v1.0.1/FrameBurst-Setup-1.0.1.exe)**:
run it and follow the steps. If you already have FrameBurst installed, it will offer this update on its own
(or choose **Check for updates** from the tray menu). Your settings are kept.

**Requirements:** Windows 10 version 2004 or later, or Windows 11 (64-bit), and a Direct3D 11 GPU.

## What's new

### New Settings window
- Mica background, a Windows 11 style title bar, and a side menu with **Capture**, **Output** and **Updates**
  pages.
- Every option is a card with an icon and a short description. On/off options use toggle switches.
- The capture delay is a number box with arrow buttons that step by 250 ms.
- **Browse…** opens the standard Windows folder picker.
- The **Updates** page shows your version and has a **Check for updates** button, so you no longer need the
  tray menu to check.
- If the settings can't be saved, the error appears inside the window and your changes stay on screen.
- The window follows your light or dark theme.

### New tray menu
- Right-clicking the tray icon opens a WinUI menu with rounded corners, icons and your theme's colours.
- Each capture item shows the hotkey assigned to it, such as *Ctrl + PrintScreen*.
- Left-clicking the icon still captures a region.

## Notes
- The Windows App SDK is included in the installer, so nothing extra needs to be installed. The installer
  is larger because of it.
- The screenshot overlay, annotation tools and colour picker have not changed.
