# FrameBurst 1.4.0

A redesigned interface: a calmer Settings window, a frosted-glass capture toolbar, and capture tools that
finally scale properly on high-DPI displays.

## Download

**[FrameBurst-Setup-1.4.0.exe](https://github.com/LunoviaVR/FrameBurst/releases/download/v1.4.0/FrameBurst-Setup-1.4.0.exe)**:
run it and follow the steps. If you already have FrameBurst installed, open **Settings › About** and choose
**Check for updates**. Your settings are kept.

**Requirements:** Windows 10 version 2004 or later, or Windows 11 (64-bit). A Direct3D 11 GPU is recommended.

## New look
- **Settings** groups related options into sections instead of a separate card for every row, with clearer
  headings and a flatter About page. FrameBurst blue is now the accent everywhere (buttons, toggles,
  selection, focus) in both light and dark mode.
- **Capture toolbar and hint** are frosted glass that picks up the colours of your screen, with new icons
  from the same Segoe Fluent set as Settings and clearer hover, pressed, selected and disabled states.
- **Size label, magnifier and colour picker** use the same rounded panels and a monospace readout.
- **Dialogs and the tray menu** match the new style; dialogs use a translucent acrylic background.

## Improvements
- The capture toolbar, hint, magnifier and colour picker now scale with the display scaling of the monitor
  they're on. Before, they were drawn at a fixed pixel size and looked small at 150 % and above.
- The Settings window can be resized smaller: below 760 px the navigation shrinks to icons, and below about
  520 px each setting moves its control under its description.
- **Esc** closes Settings without saving and **Ctrl+S** saves. (While a hotkey box has focus, keys are still
  recorded as the hotkey.)
- Update status and save errors now show an icon as well as colour, and screen readers announce update
  status changes and name every setting's control.
- With **Transparency effects** off or a high-contrast theme on, the glass surfaces switch to solid panels.

## Fixes
- The last lines of a long message (for example update release notes) could be cut off at the bottom of a
  dialog.
- Exiting FrameBurst while the tray menu was open could show an error.

## Good to know
- Hotkeys, capture, file output and all settings work exactly as before; this release only changes how
  FrameBurst looks.
