# FrameBurst 1.2.0

Settings has a new **About** page. You can now check for and install updates from inside FrameBurst.

## Download

**[FrameBurst-Setup-1.2.0.exe](https://github.com/LunoviaVR/FrameBurst/releases/download/v1.2.0/FrameBurst-Setup-1.2.0.exe)**:
run it and follow the steps. If you already have FrameBurst installed, open **Settings › About** and choose
**Check for updates**. Your settings are kept.

**Requirements:** Windows 10 version 2004 or later, or Windows 11 (64-bit), and a Direct3D 11 GPU.

## What's new

### About page
- **Settings › Updates** is now **Settings › About**. It shows a short description of FrameBurst, the version
  you have installed, and links to the release notes and source code.

### Updates from inside the app
- Choose **Check for updates** on the About page. If a new version is out, press **Download and install**.
  FrameBurst downloads the update, shows a progress bar, checks the file against GitHub's SHA-256 checksum,
  installs the update in the background and restarts. You don't need to download the installer yourself.
- **Check for updates** in the tray menu now opens the About page and starts the check.
- Automatic daily checks still work as before. You can turn them on or off on the same page.

### Support FrameBurst
- New **Tip** button on the About page. It opens Cash App ($LunoviaVR). FrameBurst stays free and open source.
