# FrameBurst 1.0.0

The first release of FrameBurst: a system tray screenshot tool for Windows that captures the highest-quality
image possible, with every step done on the GPU through Direct3D 11 (NVIDIA, AMD and Intel).

## Download

**[FrameBurst-Setup-1.0.0.exe](https://github.com/LunoviaVR/FrameBurst/releases/download/v1.0.0/FrameBurst-Setup-1.0.0.exe)**:
run it and follow the steps.

- No admin rights needed. It installs for your user account by default, or for all users if you choose.
- .NET is included, so nothing else needs to be installed.
- Optional: start with Windows (on by default) and a desktop shortcut.
- Uninstall any time from *Settings › Apps › Installed apps*.

**Requirements:** Windows 10 version 2004 or later, or Windows 11 (64-bit), and a Direct3D 11 GPU.

## Highlights

### Pixel-exact, GPU-accelerated capture
- Each monitor's frame is taken straight from the Windows compositor with **Windows Graphics Capture** as a
  Direct3D 11 texture, with no GDI copies.
- All monitors are captured at the same moment, each on the GPU that drives it, including hybrid laptops
  with integrated and dedicated graphics.
- A D3D11 compute shader converts every frame to 8-bit sRGB **exactly**, whether Windows composites in 8-bit
  or FP16 (Auto Color Management). All 16,777,216 colours are verified to come out unchanged.
- About **45 ms** from hotkey to pixels in memory for three monitors (9.9 MP). The shader itself runs in about
  0.5 ms.

### Capture modes
| Input | Captures |
|---|---|
| PrintScreen | A region (drag, or click a window) |
| Ctrl+PrintScreen | All monitors |
| Shift+PrintScreen | The monitor under the cursor |
| Alt+PrintScreen | The active window |
| Click the tray icon | A region, after a 1-second delay |

- Every hotkey can be changed in Settings.
- **Hotkeys work over full-screen games and apps.** A low-level keyboard hook catches the key before the game
  does, so the capture still starts, and the game doesn't receive the key press.

### Region overlay
- Freezes the screen across every monitor.
- Drag to select, or click a window to take it.
- **Enter** takes the monitor under the cursor, **F** takes the whole desktop.
- Arrow keys move the cursor 1 px for precise edges.
- A magnifier shows the surrounding pixels, the screen coordinates and the colour under the cursor.

### Built-in editor
Draw on the frozen screen before choosing what to capture:
- **Pen**, **Highlighter**, **Arrow**, **Rectangle**, **Text** and **Blur**, each with a one-key shortcut
  (P, H, A, R, T, B).
- Colour palette, adjustable line width, text size and blur strength (mouse wheel or `[` `]`).
- Undo and redo (Ctrl+Z / Ctrl+Y).
- Edits change only the pixels they cover; everything else stays pixel-perfect.

### Screen colour picker
- Freezes the screen with a magnifier and live hex/RGB readout.
- Click to copy the exact colour as `#RRGGBB`.

### Output
- Lossless PNG from a custom multi-threaded encoder, with three compression levels (speed vs file size).
- Saved to `Pictures\FrameBurst` with a customisable file name pattern using .NET date codes. A **Read more.**
  link in Settings lists every code.
- Copied to the clipboard as an image, a PNG and a file, so it pastes into chat apps, image editors and File
  Explorer.
- A notification after each capture. Click it to show the file in File Explorer.
- Optional capture delay and mouse cursor capture.

### Automatic updates
- FrameBurst checks this repository for new releases once a day and asks before installing anything.
- Updates are verified against GitHub's SHA-256 checksum, then installed silently. FrameBurst restarts on its own.
- Check any time from the tray menu (**Check for updates…**), or turn automatic checks off in *Settings › Updates*.

## Known limitations
- **HDR isn't supported.** On a monitor in Windows HDR mode, captures are clipped to SDR. Turn HDR off for that
  monitor before capturing it.
- DRM-protected video shows up black. Windows enforces this.
- On Windows 10 a yellow capture border may flash briefly around the screen. Windows 11 hides it.
- The secure desktop (UAC prompts, the lock screen) cannot be captured.
- Games running as administrator, or protected by some anti-cheat software, may block the hotkeys.
- Inverting cursors (such as the I-beam) are approximated when cursor capture is on.
