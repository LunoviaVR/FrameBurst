# FrameBurst 1.0.2

Screenshots can now be sorted into **dated subfolders**, so a busy screenshot folder stays organised by day,
month and year without any manual filing.

## Download

**[FrameBurst-Setup-1.0.2.exe](https://github.com/LunoviaVR/FrameBurst/releases/download/v1.0.2/FrameBurst-Setup-1.0.2.exe)**:
run it and follow the steps. If you already have FrameBurst installed, it will offer this update on its own
(or choose **Check for updates** from the tray menu). Your settings are kept.

**Requirements:** Windows 10 version 2004 or later, or Windows 11 (64-bit), and a Direct3D 11 GPU.

## What's new

### Dated subfolders
- New **Dated subfolders** option on the **Output** page of Settings. Turn it on and each capture is saved
  inside a subfolder of your screenshot folder named after the date it was taken.
- The default layout is `{yyyy}\{MM}\{dd}`, e.g. `Pictures\FrameBurst\2026\09\30\`. A new folder is
  created automatically when the day, month or year changes.
- The layout is fully customisable with the same `{…}` .NET date format used for file names. Use `\` to
  add folder levels, for example:
  - `{yyyy}\{MM MMMM}` → `2026\09 September\`
  - `{yyyy-MM}` → `2026-09\` (one folder per month)
  - `{yyyy}\Week {dd}` → mix plain text and dates
- The folder name and the file name use the same timestamp, so they always agree.

## Notes
- The option is off by default; existing setups keep saving exactly where they did before.
- **Open screenshot folder** in the tray still opens the top-level screenshot folder.
