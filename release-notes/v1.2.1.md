# FrameBurst 1.2.1

A small visual fix for the About page added in 1.2.0.

## Download

**[FrameBurst-Setup-1.2.1.exe](https://github.com/LunoviaVR/FrameBurst/releases/download/v1.2.1/FrameBurst-Setup-1.2.1.exe)**:
run it and follow the steps. If you already have FrameBurst installed, open **Settings › About** and choose
**Check for updates**. Your settings are kept.

**Requirements:** Windows 10 version 2004 or later, or Windows 11 (64-bit), and a Direct3D 11 GPU.

## Fixes
- The FrameBurst logo on the About page was blurry. It now uses the full-resolution 256 px artwork.
- The Cash App logo on the **Tip** button is now a sharp vector image of the real logo, so it stays crisp
  at any display scaling.
